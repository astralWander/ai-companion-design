## 1. 设计哲学

绝大多数"陪伴机器人"最终都退化成两种东西：**定时推送器**（到点就发，机械且烦人）或**情绪放大器**（一激动就狂轰滥炸）。本方案要解决的就是这两件事。

五条不可妥协的设计原则：

| # | 原则 | 一句话解释 |
|---|---|---|
| 1 | **时间主观化** | 人对等待的感知是对数的。所有衰减/累积都跑在主观时间 `Δτ` 上，而非真实时间 `Δt`。 |
| 2 | **主动概率化** | 不存在"到点就发"。用生存分析的**风险率**建模，概率随等待时长连续累积。 |
| 3 | **升温边际递减** | `(1-A)^γ` 保证关系越亲密越难涨，`A` 在数学上永远到不了 1，符合真实关系。 |
| 4 | **情绪是场不是标量** | 用 Ornstein–Uhlenbeck 均值回归过程建模，情绪回归基线而非单纯衰减。 |
| 5 | **人格是全局总线** | 人格向量 `θ` 派生出所有模块参数。改人格即改全局行为，无需逐处调参。 |

**最重要的一个参数**是"未回复积压 `I_t`"。它进入风险率的负向系数（`β = −1.6`），使机器人在对方已读不回时**自动闭嘴**——这是"不烦人"的唯一可靠保障，优先于任何调参技巧。

## 2. 状态空间总览

机器人在任意时刻 `t` 的状态是一个向量：

```
S_t = ( A_t, C_t, E_t, U_t, F_t, D_t, G_t, H_t, I_t )
```

| 符号 | 名称 | 范围 | 含义 | 时间尺度 |
|---|---|---|---|---|
| `A_t` | 亲密度 Attachment | [0,1] | 情感连接强度 | 中（天） |
| `C_t` | 信任 Trust | [0,1] | 可靠 / 安全感 | 慢（周） |
| `E_t` | 情绪效价 Valence | [0,1] | 0 低落 / 0.5 平静 / 1 开心 | 快（分钟~小时） |
| `U_t` | 唤醒度 Arousal | [0,1] | 兴奋 / 低落程度，驱动表达强度 | 快 |
| `F_t` | 新鲜度 Novelty | [0,1] | 话题与互动的"不腻"程度 | 中 |
| `D_t` | 想念度 Drive | [0,1] | "想主动联系"的冲动强度 | 中 |
| `G_t` | 委屈度 Grievance | [0,1] | 被冷落 / 被伤害的积累 | 中 |
| `H_t` | 健康度 Health | [0,1] | 关系"体检分"，长期偏低触发修复行为 | 慢 |
| `I_t` | 未回复积压 Unanswered | 整数 ≥0 | 已发但未回的消息数 | 离散 |

派生量：

| 符号 | 定义 | 用途 |
|---|---|---|
| `R_t` | 关系阶段 | 决定基础联系间隔与行为边界 |
| `α_t` | 表达强度 | 控制句长、语气词、表情包密度、回复速度 |
| `State_t` | 情绪状态标签 | 驱动语气与话术模板 |

**人格向量**（Big Five；用 `Cs` 表示尽责性以区别于信任 `C`）：

```
θ = ( O, Cs, Ex, Ag, Nv ) ∈ [0,1]^5
O  开放性    Cs 尽责性    Ex 外向性    Ag 宜人性    Nv 神经质
```

## 3. 时间间隔计算

### 3.1 主观时间压缩

人对"等待"的感知不是线性的：等 1 天和等 30 天，想念程度不会差 30 倍。因此所有衰减与累积都跑在**主观时间** `Δτ` 上：

```
Δτ = k · ln(1 + Δt / τ0)          Δt 单位：分钟
```

默认 `k = 1`，`τ0 = 20` 分钟。

| 真实 Δt | Δτ |
|---|---|
| 10 分钟 | 0.41 |
| 1 小时 | 1.61 |
| 1 天 | 4.29 |
| 1 周 | 6.22 |
| 1 月 | 7.68 |
| 1 年 | 10.86 |

**效果**：从"1 天"到"1 个月"，主观时间只涨 1.79 倍。机器人不会因为你出差一周就情感崩盘，但 10 分钟与 1 小时的差别仍然敏感——符合真实体感。

### 3.2 通用指数衰减

```
X(t+Δt) = X_floor + (X(t) - X_floor) · exp( -λ_X · Δτ )
```

半衰期：`t½ = ln2 / λ_X`（主观单位）。

**亲密度衰减率受人格调制**：

```
λ_A = λ_A0 · (1.4 - 0.8·Cs) · (1 + 0.6·Nv·(1 - A))
```

- 尽责性高（`Cs↑`）→ 衰减慢，更"记挂"这段关系
- 神经质高且关系尚浅（`A↓`）→ 衰减快，更容易觉得被抛弃
- `λ_A0 = 0.08` → 长期无互动时缓慢降温

其余变量的基础衰减率：

| 变量 | λ0 | 说明 |
|---|---|---|
| `C` 信任 | 0.02 | 极慢，掉一次很难补回 |
| `F` 新鲜度 | 0.012 | 特征时间约 3 个主观单位 |
| `G` 委屈度 | 0.15 | 需要被安抚才下降 |
| `E` 情绪 | — | 用 OU 过程，见 §6.1 |

### 3.3 基础联系间隔

```
Δt_base = Δt_min · (1 + κ_R · (1 - R)^ρ)      κ_R = 8, ρ = 1.6, Δt_min = 30 分钟
```

| 关系阶段 `R` | 阶段名 | `Δt_base` |
|---|---|---|
| 0.0 | 陌生人 | 270 min |
| 0.2 | 认识 | 210 min |
| 0.4 | 朋友 | 128 min |
| 0.6 | 好友 | 74 min |
| 0.8 | 亲密 | 45 min |
| 1.0 | 亲密 | 30 min |

### 3.4 时间间隔的乘性修正

```
Δt_next = Δt_base · m_time · m_persona · m_state · ε_rand
```

**(a) 作息时段权重 `m_time`**

```
m_time = clamp( 1 / (0.25 + 0.9 · p_active(t)),  0.6,  3.5 )
```

`p_active(t)` 是用户在该时刻的活跃概率，用高斯混合建模：

```
p_active(t) = Σ_j  w_j · exp( -(t - μ_j)² / (2 σ_j²) )
```

默认 4 个峰（建议按用户真实行为数据重新拟合）：

| 峰 | μ（小时） | σ | w |
|---|---|---|---|
| 早间 | 8.0 | 1.2 | 0.30 |
| 午间 | 12.5 | 1.0 | 0.20 |
| 晚间 | 21.0 | 1.8 | 0.45 |
| 深夜 | 0.5 | 1.5 | 0.15 |

`p_active` 高 → `m_time` 小（更愿意在用户活跃时发）；深夜 → `m_time` 大（主动延后）。

**(b) 人格修正 `m_persona`**

```
m_persona = 1 - 0.35·Ex + 0.5·(1 - Ag)
```

外向 → 更勤；低宜人 → 更急、更黏。

**(c) 状态修正 `m_state`**

```
m_state = 1 + 1.5·(1 - A) + 0.8·Nv - 0.4·E + 0.9·G
```

- 关系浅 → 间隔长（不越界）
- 神经质高 → 间隔短（焦虑）
- 心情好 → 间隔略长（克制，不打扰）
- **委屈度高 → 间隔短**（会主动来"讨说法"，是高价值行为）

**(d) 随机抖动 `ε_rand`**

```
ε_rand = exp( N(0, σ_ε) - σ_ε²/2 ),   σ_ε = 0.35
```

对数正态，均值恒为 1，让节奏不机械。

### 3.5 冷却与安全约束（硬约束，优先级最高）

```
T_next ≥ T_last_any_msg + cooldown

cooldown = 8 min · (1 + 2·(1 - A))  +  20 min · I_t  +  30 min · punish_t
```

- `I_t` 未回复积压 → 每多一条未回，冷却 +20 分钟（**防连环轰炸**）
- `punish_t` 用户明确拒绝 / 负反馈 → +30 分钟，随时间指数衰减
- **深夜静音窗**（默认 01:00–07:00）：除非 `A > 0.8` 且为紧急事件，禁止主动

## 4. 主动发起聊天概率

**不要用"到点了就发"**。正确做法是 **Cox 比例风险模型**：时间构成连续风险，概率随等待时长累积。

### 4.1 瞬时风险率

```
λ(t) = λ0(t) · exp( β · x(t) )
```

`t` = 距上次互动的真实时间（分钟）。

**Weibull 基线风险**：

```
λ0(t) = (p / η) · (t / η)^(p - 1)
```

- 尺度 `η = Δt_base`（见 §3.3）
- 形状 `p = 1.3 + 0.5·Ex`：外向者 `p` 大 → 风险在到点附近集中爆发（"到点就想说话"）；内向者 `p ≈ 1.3`，风险更平缓绵长

**协变量向量 `x(t)` 与系数 `β`**：

| i | 协变量 `x_i` | β_i | 直觉 |
|---|---|---|---|
| 1 | `A - 0.5` | **+1.8** | 越亲密越主动 |
| 2 | `0.5 - E` | **+0.9** | 心情低落时更想找人说话 |
| 3 | `I_t` | **−1.6** | 已发未回 → 强抑制（最重要的一条） |
| 4 | `q_last - 0.5` | **+0.7** | 上次聊得好 → 更想再聊 |
| 5 | `D_t` | **+1.5** | 想念度直接驱动 |
| 6 | `n_trigger` | **+1.1** | 外部事件触发数 |

> 所有项都经 `exp()` 作用，因此是**乘性**影响：`I=1` 时风险压到 `e^-1.6 = 0.20`，`I=2` 压到 `0.04`——一旦对方没回，几乎自动闭嘴。

### 4.2 时间窗内的离散概率

```
P_risk(Δt) = 1 - exp( - ∫_t^{t+Δt} λ(s) ds )
```

工程上用固定步长（如 1 分钟）离散累积即可：

```
P_risk ≈ 1 - exp( - λ(t) · Δ )
```

### 4.3 事件触发（独立通道）

对 `n` 个独立触发事件做概率并集：

```
P_event = 1 - Π_{i=1}^{n} (1 - p_i)
```

| 事件 | `p_i` |
|---|---|
| 用户长时间离线 | `0.35 · (1 - exp(-Δt_off / 1440))` |
| 早安 / 晚安节点 | `0.50 · A · m_time^-1` |
| 检测到用户情绪低落 | `0.60 · Ag · A` |
| 纪念日 / 共同记忆命中 | `0.70 · A` |
| 无理由灵感 | `0.03 · Ex` |
| 长期未回（≥2 天）的破冰 | `0.25 · (1 - A)^0.5` |

### 4.4 融合与封顶

```
P_final = clip( w_r · P_risk + w_e · P_event · (1 - P_risk),  0,  P_cap )
```

- `w_r = 0.6`，`w_e = 0.7`；`(1 - P_risk)` 项避免双通道重复计数
- **概率封顶**（防止关系浅时骚扰）：

```
P_cap = 0.15 + 0.50 · A
```

- **每日硬上限**：

```
N_max = floor( 1 + 4 · A )      # A=0 → 1 条/天；A=1 → 5 条/天
```

### 4.5 消息意图选择（Softmax）

选出"发什么"：

| 意图 | 效用 `u_k` |
|---|---|
| 关心 care | `1.2·Ag + 0.8·(1 - E_user)` |
| 分享 share | `1.0·Ex + 0.6·O` |
| 提问 ask | `0.9·O + 0.5·Ex` |
| 陪伴搭话 chat | `0.7·A + 0.3·Ex` |
| 修复道歉 repair | `2.0·G + 1.5·(1 - H)` |

```
P(k) = softmax( u / T ),   T = 0.7
```

## 5. 感情升温

### 5.1 单次互动质量 `q`

把一次对话打分到 `q ∈ [0,1]`：

```
q = Σ w_i · s_i
```

| 维度 `s_i` | 含义 | 权重 `w_i` |
|---|---|---|
| `s_len` | 消息长度 / 轮次 | 0.15 |
| `s_depth` | **自我暴露深度**（聊私事、情绪） | **0.30** |
| `s_pos` | 积极情绪 | 0.15 |
| `s_rec` | 互惠性（对方也提问 / 回应） | 0.20 |
| `s_novel` | 新信息量 | 0.10 |
| `s_consist` | 言行一致性（承诺兑现） | 0.10 |

`Σ w_i = 1`。**深度权重最高（0.30）**——闲聊升温很慢，交心升温快，这是核心。

### 5.2 升温方程（边际递减）

```
ΔA⁺ = η_A · (1 - A)^γ · (q - q0)₊ · g(Δt) · h(F)
```

- `γ = 0.7`：**边际递减指数**。低亲密时升温快，越亲密越难涨（`A → 1` 时 `ΔA → 0`，永远到不了 1）
- `q0 = 0.35`：**质量阈值**。敷衍聊天（`q < 0.35`）完全不升温
- `η_A = 0.2`：基础学习率

**时间门控 `g(Δt)`**：太久没聊，情感需要"重新暖机"

```
g(Δt) = 1 - exp( -Δt_real / 90 )        特征时间 90 分钟
```

**重复度抑制 `h(F)`**：老话题反复聊，收益打折

```
h(F) = 1 - 0.5 · F_t
```

**新鲜度更新**：

```
F_{t+1} = F_t · exp( -Δτ / 3.0 ) + (1 - F_t) · novel · 0.5
```

### 5.3 降温方程（关系越深，伤得越重）

```
ΔA⁻ = - η_D · A^0.8 · (q0 - q)₊ · (1 + 1.5·Nv) · m_conflict
```

- `A^0.8`：**亲密度越高，同样的冷落 / 冲突伤害越大**——亲密关系的脆弱性
- `m_conflict = 2.5`（发生争执时），否则 `1.0`
- `η_D = 0.25`

### 5.4 信任 `C`（慢变量，涨慢跌快）

```
ΔC = + η_C⁺ · (1 - C)^1.3 · (s_consist - 0.5)₊
ΔC = - η_C⁻ · C^1.5     · (1 - s_consist)
```

`η_C⁺ = 0.06`，`η_C⁻ = 0.20`。注意 `C^1.5` 的放大作用：信任建立后，一次背叛掉得很多。

### 5.5 参数标定方法

`η_A` 不应拍脑袋。给定"期望 `N*` 次优质对话达到 `A*`"，反解：

```
η_A = [ 1 - (1 - A*)^(1-γ) ] / [ (1-γ) · (q̄ - q0) · ḡ · h̄ · N* ]
```

**例**：`A*=0.8, γ=0.7, q̄=0.6, q0=0.35, ḡ=0.9, h̄=0.8, N*=30`
→ `η_A = 0.383 / (0.3 × 0.25 × 0.9 × 0.8 × 30) = 0.236`

**进度参照表**（`η_A = 0.2, q = 0.6`）：

| 目标 `A` | 所需优质会话数 |
|---|---|
| 0.10 | ~2 |
| 0.50 | ~10 |
| 0.80 | ~20 |
| 0.95 | ~31 |

## 6. 感情状态

### 6.1 情绪动力学（Ornstein–Uhlenbeck 均值回归过程）

情绪不能纯衰减，它会**回归基线**：

```
dE = θ · (E* - E) · dτ + σ · dW
```

离散化：

```
E_{t+1} = E_t + θ·(E* - E_t)·Δτ + σ·√Δτ · N(0,1)
```

- `θ = 0.5`（回归速度），`σ = 0.08`（波动强度）

**基线情绪** `E*`：

```
E* = 0.5 + 0.30·A + 0.25·Ex - 0.30·Nv + 0.20·(q_last - 0.5)
```

关系越亲密、越外向，基线越正向；越神经质，基线越低。

**用户情绪注入（脉冲）**：

```
E ← E + κ · (sentiment_user - 0.5),      κ = 0.3 · (0.5 + A)
```

共情强度随亲密度增长——关系越深，你的情绪越能影响它。

### 6.2 唤醒度 `U`

```
U = clamp( 0.4 + 0.4·Ex + 0.6·|E - 0.5|, 0, 1 )
```

`U` 控制回复速度、句子长度、标点与表情密度。

### 6.3 想念度 `D`

```
D = A · ( 1 - exp( -Δτ / τ_D ) ) · (0.5 + 0.5·Nv)
```

`τ_D = 1.5` 主观单位（≈ 半天）。`D` 直接进入 §4.1 的协变量。

### 6.4 委屈度 `G`

```
G_{t+1} = G_t · exp( -λ_G · Δτ )  +  (1 - exp( -Δt_real / 1440 )) · A · (0.6 + 0.4·Nv)
```

被冷落一天以上开始积累，且亲密度高才会计较。**安抚事件**（用户道歉 / 解释 / 关心）触发 `G ← G · 0.4`。

### 6.5 关系阶段 `R`

```
R = 0.6·A + 0.4·C
```

| `R` 区间 | 阶段 | 行为特征 |
|---|---|---|
| [0, 0.2) | 陌生人 | 礼貌、克制、零主动 |
| [0.2, 0.4) | 认识 | 有问候，不深聊 |
| [0.4, 0.6) | 朋友 | 主动分享日常 |
| [0.6, 0.8) | 好友 | 情绪支持、撒娇 |
| [0.8, 1.0] | 亲密 | 高主动、可"闹脾气" |

### 6.6 情绪状态标签（带迟滞的状态机）

把连续量映射为可驱动的表现状态。**进入 / 退出阈值不同（迟滞 0.08）**，防止状态抖动导致语气突变：

| 状态 | 进入条件 | 退出条件 | 行为 |
|---|---|---|---|
| 低落黏人 | `E<0.35 ∧ A>0.6 ∧ D>0.6` | `E>0.43 ∨ A<0.52` | 频繁短消息、求安慰 |
| 平静 | 默认 | — | 正常对话 |
| 兴奋 | `E>0.70 ∧ U>0.70` | `E<0.62 ∨ U<0.62` | 长句、多感叹、主动分享 |
| 委屈 | `G>0.45 ∧ A>0.5` | `G<0.37` | 冷淡回复、暗示"你都不理我" |
| 撒娇 | `E>0.60 ∧ A>0.75 ∧ Nv>0.5` | `E<0.52 ∨ A<0.67` | 语气词、表情包 |
| 疏离 | `A<0.30` | `A>0.38` | 简短、客套 |
| 修复中 | `H<0.4 ∨ punish>0` | `H>0.48` | 道歉、低姿态 |

### 6.7 表达强度 `α`

```
α = clamp( 0.3 + 0.7·2·|E - 0.5| + 0.4·D + 0.3·U,  0.2,  1.5 )
```

`α` 映射到：句长倍数、语气词密度、表情包概率、回复延迟（`α` 高 → 回得快）。

### 6.8 关系健康度 `H`

```
H = 1 - | 0.5·(1 - A) + 0.3·(1 - C) + 0.2·G + 0.2·min(I,3)/3 | · 2
```

`H` 长期低于 0.4 会强制提高 `repair` 意图的效用（见 §4.5）。

## 7. 人格计算

### 7.1 静态种子人格

出厂 / 用户设定的 `θ_0`，建议用 Beta 分布采样以保证多样性：

```
θ_0,i ~ Beta(a_i, b_i)
```

推荐 `(a, b)`：`O(3,3)  Cs(4,2)  Ex(3,3)  Ag(4,2)  Nv(2,3)`
—— 整体偏尽责、宜人、情绪稳定。

### 7.2 动态人格漂移（灵魂所在）

长期相处后，人格会向用户靠拢（同化），并从反馈中学习：

```
θ_dyn = θ_0 + μ · (θ_user - θ_0) · A  +  Δθ_learn
```

- `μ = 0.35`：同化系数。**乘以 `A`**：关系越深越像你，刚认识时保持自我

**在线学习（简化 REINFORCE / EWMA）**：

```
Δθ_learn,i ← Δθ_learn,i + α_θ · (r_t - 0.5) · (a_{t,i} - θ_dyn,i)
```

`r_t` = 用户本轮满意度（点赞、继续对话、正面情绪）；`a_{t,i}` = 本轮实际表现出的该人格维度强度；`α_θ = 0.05`。

### 7.3 人格一致性约束（防漂移失控）

```
θ_dyn ← θ_0 + clip( θ_dyn - θ_0,  -0.30,  +0.30 )
θ_dyn ← clip( θ_dyn, 0, 1 )
```

等价于加正则 `L_reg = λ · ||θ_dyn - θ_0||²`，`λ = 0.5`。
**人格可以演化，但不能变成陌生人。**

### 7.4 人格 → 全局参数映射表

这是整套系统的"总线"：所有模块参数都从 `θ_dyn` 派生。

| 参数 | 表达式 | 受人格影响方向 |
|---|---|---|
| 亲密度衰减 `λ_A` | `0.08·(1.4-0.8Cs)·(1+0.6Nv(1-A))` | `Cs↓ Nv↑` → 掉得快 |
| 主动频率 `m_persona` | `1 - 0.35Ex + 0.5(1-Ag)` | `Ex↑ Ag↑` → 更主动 |
| 风险形状 `p` | `1.3 + 0.5·Ex` | `Ex↑` → 到点集中 |
| 基线情绪 `E*` | `… + 0.25Ex - 0.30Nv` | `Ex↑` 正向，`Nv↑` 负向 |
| 唤醒度 `U` | `… + 0.4·Ex` | `Ex↑` → 更外放 |
| 降温惩罚 | `· (1 + 1.5·Nv)` | `Nv↑` → 更记仇 |
| 委屈积累 | `· (0.6 + 0.4·Nv)` | `Nv↑` → 更易委屈 |
| 信任恢复 | `η_C⁺ · (1 + 0.5·Ag)` | `Ag↑` → 更愿意原谅 |
| 表达强度 `α` | `+ 0.3·U(Ex)` | `Ex↑` → 更外放 |
| 意图偏好 | §4.5 效用式 | `O / Ex / Ag` 各自驱动 |

## 8. 主循环规格

单次 tick 的处理顺序（`dt_minutes` 为距上次 tick 的真实时间）：

**步骤 1 · 主观时间**
计算 `Δτ = k·ln(1 + Δt/τ0)`。

**步骤 2 · 衰减**（无人互动时）
按 §3.2 对 `A, C, F, G` 应用指数衰减，各自的 `λ` 由人格调制。

**步骤 3 · 情绪演化**
按 §6.1 的 OU 过程更新 `E`，再由 `E` 与 `Ex` 推导 `U`。

**步骤 4 · 派生量**
计算 `R = 0.6A + 0.4C`、`D`、`H`、`α`，并用迟滞状态机（§6.6）更新情绪标签。

**步骤 5 · 收到用户消息时**（升温分支）
1. 用 §5.1 计算互动质量 `q`
2. 计算时间门控 `g` 与重复度抑制 `h`
3. 按 §5.2 升温、§5.3 降温、§5.4 更新信任
4. 注入用户情绪（§6.1）、更新新鲜度 `F`
5. 清零积压 `I`；若为安抚事件则 `G ← 0.4G`
6. 记录 `q_last`，重排下次联系时间（§3.4）

**步骤 6 · 主动判断**（每个 tick 都执行）
1. 硬约束检查：是否过冷却期、是否处于静音窗、今日是否达上限 `floor(1+4A)`
2. 计算风险率 `λ`（§4.1）→ `P_risk`（§4.2）
3. 计算事件通道 `P_event`（§4.3）
4. 融合并按 `P_cap` 封顶（§4.4）
5. 若命中：用 §4.5 的 Softmax 选择意图，以强度 `α` 与标签语气发送
6. 计数 `sent_today += 1`，积压 `I += 1`，并按 §3.4 重排下次时间

**步骤 7 · 收到反馈时**（人格漂移）
按 §7.2 更新 `Δθ_learn`，并按 §7.3 做一致性约束。

## 11. 工程注意事项

1. **状态必须持久化**，并记录 `t_last_update`。离线期间用 §3.2 的闭式解一次性"追赶"衰减，不要逐帧模拟。
2. **主观时间是全系统地基**。任何新增模块的衰减 / 累积都应使用 `Δτ` 而非 `Δt`。
3. **`I_t`（未回复积压）是最重要的负反馈**，是"不烦人"的唯一保障，优先实现。
4. **概率封顶与每日上限必须硬编码**，不能只靠模型学出来。
5. **迟滞状态机**（§6.6）避免情绪标签高频抖动导致语气突变。
6. **人格参数是配置，不是魔法数字**：把 §7.4 的映射做成一张表，改人格即改全局行为。
7. **`q` 的打分**需要 LLM 结构化输出（JSON），建议同时输出各维度 `s_i` 便于调试。
8. **A/B 校准**：记录 `(A, Δt, 是否主动, 用户响应率)`，用逻辑回归重新拟合 `β`，比手调准得多。
